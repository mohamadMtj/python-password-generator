# 🔐 Python Password Generator

A simple command-line password generator built with Python.

This project generates strong random passwords based on the number of letters, numbers, and symbols selected by the user. It was created as part of my Python learning journey.

---

## ✨ Features

- 🔐 Generates random passwords
- 🔤 Custom number of letters
- 🔢 Custom number of digits
- 🔣 Custom number of symbols
- 🔀 Randomly shuffles characters for better security
- 💻 Command-line interface

```bash

```

Run the program

```bash
python PyPassWord.py
```
